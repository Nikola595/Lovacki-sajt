# Lovački sajt

Ovo je gotov responsive početak sajta napravljen kao moderna lovačka prezentacija.

## Kako da ga otvoriš
1. Raspakuj ZIP.
2. Otvori `index.html` u Chrome-u.
3. Za pravi hosting uploaduj sve fajlove na hosting.

## Šta treba zameniti
- naziv društva u `index.html`
- kontakt podatke
- tekstove
- fotografije u folderu `assets`
- broj članova, hektare i godinu tradicije

Za sada je ubačena jedna generisana fotografija kao vizuelni placeholder. Najbolji sledeći korak je da se ubace tvoje stvarne fotografije lovišta, članova, divljači i objekata.
